# UNIZA Hub · 1ZD312

Static, shareable landing page for classmates. It contains no accounts, passwords,
cookies, proxy, analytics, or server-side state. Each visitor's display name is
stored only in that visitor's own browser via `localStorage`; the same Netlify
URL therefore remains private and personal for every classmate.

## Deploy to Netlify

Drag this folder into Netlify Drop, or create a new Netlify site with this folder
as the publish directory. No build command is required.

The timetable opens the official UNIZA page for study group `1ZD312` using its
official `id=1ZD312&sq=2` URL.
